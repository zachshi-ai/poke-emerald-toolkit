# 宝可梦绿宝石改版工具链

把 GBA《绿宝石》的扩充版源码改造成「中文 + 可调试 + 装得进手机」的一套脚本。这里只放工具与壳工程，**不含游戏 ROM、不含游戏源码、不含美术与文本数据**。

## 这条工具链解决什么

| 工具 | 作用 |
|---|---|
| `tools/mt_all.py` · `translate_pool.py` · `batch_file.py` | 提取源码里的 `_("...")` 字符串批量机翻成中文；占位符保护、缓存、多引擎回退 |
| `tools/apply_safe.py` | 安全回写：只动可安全替换的文件，跳过定长结构与数据目录，逐文件编译校验失败即回滚 |
| `tools/pipeline.py` | 逐文件流水：翻译 → 写回 → 编译校验 → 失败回滚，支持断点续跑 |
| `tools/gen_cjk.py` | 中文点阵字库 + charmap 生成（PIL 逐字渲染进字库，避开原版字库容量限制） |
| `tools/merge_c.py` · `merge_desc.py` · `merge_zh.py` | 把中文底座与功能分支的改动合并回主树 |
| `tools/patch_debug.py` · `add_editor.py` · `patch_debug2.py` | 调试菜单改造：新增道具、改道具数量、新增/修改队伍宝可梦及其种族值、技能与 PP |
| `tools/expand_wild.py` · `expand_wild_zh.py` | 遇敌表全世代扩展 |
| `tools/prep_apk.py` | 从链接脚本的符号表里取出改动过的只读段，落成运行时可读的内存配置 |
| `tools/setup_all.py` | 从原始源码重建并重放全部功能补丁（不含批量机翻） |
| `tools/port_features.py` | 把功能补丁移植到中文底座上：调试菜单、遇敌扩世代、种族值持久化 |
| `tools/story_*.py` | 剧情文本替换样例 |
| `app/` | 手机壳工程：GBA 运行时 + 全屏视图 + 存档/图鉴读写桥 |

## 几个关键结论

- **EWRAM 扩展不可行**：改动运行时内存布局后，原版存档与事件脚本的地址假设全部失效，回滚成本高于收益；改为把新增数据放进只读段并在启动时拷贝，再用 `prep_apk.py` 产出运行时可读的内存配置
- **种族值必须落盘**：只改内存里的表，重启即失效；正确做法是写入存档块并让读取路径优先走存档
- **字库是硬约束**：中文不能靠替换字体文件，要重新生成点阵字库并同步 charmap，否则码位对不上
- **翻译要防污染**：机翻会把占位符、控制码一起改掉，回写前必须保护 `{...}` 与转义序列，并跳过定长结构文件

## 工程

```
app/
  AndroidManifest.xml
  java/com/stepx/pokeemerald/      运行时桥、全屏视图、存档与图鉴读写
  jni/gbaemu.c                     运行时对外接口（编译为 .so，需自行构建）
  assets/                          运行时内存配置
tools/                             上述脚本
```

脚本里的路径按原开发环境写死（`/root/build/...`），换机器时改文件顶部的常量即可。
